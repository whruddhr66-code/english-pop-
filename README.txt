# English Pop! 웹앱 배포 파일

## 포함 파일
- `index.html`: 학습 앱
- `manifest.webmanifest`: 홈 화면 설치 설정
- `sw.js`: 기본 오프라인 캐시
- `icon.svg`: 앱 아이콘

## 가장 쉬운 공개 방법: GitHub Pages
1. GitHub 계정으로 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일 4개를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정한 뒤 저장합니다.
5. 공개된 `https://...github.io/.../` 주소를 스마트폰과 태블릿에서 엽니다.

## 기기에 홈 화면 추가
- Android/Chrome: 웹앱 주소 열기 → 브라우저 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- iPhone/iPad/Safari: 공유 메뉴 → `홈 화면에 추가`

설치/오프라인 캐시 기능은 HTTPS 주소에서 작동합니다. 로컬 HTML 파일로 직접 열 때는 서비스 워커가 작동하지 않습니다.

## 학습 기록 안내
현재 학습 기록은 각 기기의 브라우저 저장소에 남습니다. 로그인이나 여러 기기 간 동기화는 포함되어 있지 않습니다. 공유 기기에서는 기록이 다른 사용자에게 보일 수 있으니 개인 정보는 입력하지 마세요.
